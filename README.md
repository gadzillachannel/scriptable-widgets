# Scriptable Widgets 📱

ชุด Widget สำหรับแอป [Scriptable](https://scriptable.app/) บน iOS ไว้ท่องศัพท์ / เรียนภาษา
บน Home Screen และ Lock Screen โดย [Gadzilla Channel](https://github.com/gadzillachannel)

วิดเจ็ตจะสุ่มคำศัพท์ขึ้นมาแสดงเป็นระยะ แตะเพื่ออ่านออกเสียง หรือแตะเพื่อสุ่มคำใหม่ได้

---

## 📂 โครงสร้างโฟลเดอร์

จัดแยกตาม **ภาษา** เป็นหัวข้อหลัก แล้วในแต่ละภาษาแยกเป็นวิดเจ็ตย่อย
หยิบเฉพาะภาษาที่อยากเรียนไปใช้ได้เลย

```
scriptable-widgets/
├── japanese/        🇯🇵 ภาษาญี่ปุ่น
│   └── kanji-n5/    คันจิ JLPT N5 (101 ตัว) — hardcode
├── chinese/         🇨🇳 ภาษาจีน
├── english/         🇬🇧 ภาษาอังกฤษ
├── korean/          🇰🇷 ภาษาเกาหลี
└── _shared/         โค้ด / เทมเพลตที่ใช้ร่วมกัน
```

## 🧩 รูปแบบการโหลดข้อมูล (3 แบบ)

วิดเจ็ตแต่ละตัวจะระบุไว้ว่าใช้แบบไหน เลือกตามความสะดวก:

| แบบ | คำอธิบาย | เหมาะกับ |
|-----|----------|----------|
| **Hardcode** | ฝังคลังคำศัพท์ไว้ในไฟล์ `.js` เลย ไม่ต้องต่อเน็ตเพื่อโหลดคำ | ชุดคำนิ่ง ๆ ไม่เปลี่ยนบ่อย เช่น Kanji N5 |
| **Dynamic (บางส่วน)** | ตัววิดเจ็ตฝังในเครื่อง แต่ดึง *เฉพาะคำศัพท์* จากไฟล์ภายนอก (เช่น JSON บน repo) | อยากอัปเดตคำได้โดยไม่ต้องแก้โค้ด |
| **Dynamic (ทั้งหมด)** | โหลดทั้งโค้ดและข้อมูลจากภายนอกตอนรัน | อัปเดตทุกอย่างจากศูนย์กลาง ผู้ใช้ไม่ต้องก๊อปโค้ดใหม่ |

> ตอนนี้มีแค่ **Kanji N5 (hardcode)** เป็นตัวแรก ส่วนภาษาอื่นเป็นโฟลเดอร์เปล่าไว้รอตัวอย่างเพิ่ม

## 🚀 วิธีติดตั้ง (ทั่วไป)

1. ติดตั้งแอป **Scriptable** จาก App Store
2. เปิดไฟล์ `.js` ของวิดเจ็ตที่ต้องการ คัดลอกโค้ดทั้งหมด
3. ในแอป Scriptable กด **+** สร้างสคริปต์ใหม่ แล้ววางโค้ด
4. ตั้งชื่อสคริปต์ให้ตรงกับที่ระบุไว้ในแต่ละวิดเจ็ต (สำคัญ ถ้ามีปุ่มสุ่ม)
5. เพิ่ม Scriptable Widget บน Home / Lock Screen แล้วเลือกสคริปต์นี้

> วิดเจ็ตบางตัวต้องสร้าง **Shortcut** เพิ่มสำหรับอ่านออกเสียง (เช่น `SpeakJP`)
> ดูรายละเอียดในหัวคอมเมนต์ของไฟล์แต่ละตัว
