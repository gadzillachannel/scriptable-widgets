# _shared — เทมเพลตกลาง

โค้ด/เทมเพลตที่ใช้ร่วมกันในการสร้างวิดเจ็ตท่องศัพท์ภาษาใหม่

## `widget-template.js`

เทมเพลตแบบ **hardcode** ถอดมาจาก `japanese/kanji-n5/Kanji N5.js`
ก๊อปไปสร้างวิดเจ็ตภาษาอื่นได้เลย โดยแก้แค่ 3 จุด

### วิธีใช้

1. ก๊อปไฟล์ไปไว้ในโฟลเดอร์ภาษา เช่น `chinese/hsk1/HSK1.js`
2. แก้ 3 ส่วนนี้:
   - **`CONFIG`** — ชื่อ Shortcut อ่านออกเสียง, ป้าย badge (`deckLabel`), ฟอนต์
   - **`dayImages` / `nightImages`** — URL รูปพื้นหลังแนวนอน (กลางวัน/กลางคืน)
   - **`vocabList`** — คลังคำศัพท์ ตามโครง field ด้านล่าง
3. ในแอป Scriptable: สร้างสคริปต์ใหม่ ตั้งชื่อให้ตรงกับชื่อไฟล์ (ปุ่มสุ่มอ้างอิงชื่อสคริปต์)
4. สร้าง Shortcut อ่านออกเสียง ชื่อตรงกับ `CONFIG.speakShortcutName`
   (ข้างใน: รับ Text → Speak Text → ตั้งภาษา/เสียงให้ตรงกับภาษาที่เรียน)

### โครงข้อมูลคำศัพท์ (`vocabList`)

| field | ความหมาย | ตัวอย่าง (ญี่ปุ่น) | ตัวอย่าง (อังกฤษ) |
|-------|----------|-------------------|-------------------|
| `word` | คำหลัก โชว์ตัวใหญ่ | `一` | `apple` |
| `reading` | คำอ่าน/ออกเสียงหลัก (ใส่ `-` ถ้าไม่มี) | `いち` | `/ˈæp.əl/` |
| `reading2` | คำอ่านสำรอง (ใส่ `""` ถ้าไม่มี) | `イチ` | `""` |
| `meaning` | ความหมาย (ภาษาผู้เรียน) | `หนึ่ง` | `แอปเปิล` |
| `example` | ตัวอย่าง/คำประสม | `一人 (ひとり)` | `an apple a day` |
| `exMean` | ความหมายของตัวอย่าง | `คนเดียว` | `กินแอปเปิลวันละลูก` |
| `speak` | (ไม่บังคับ) ข้อความให้ Siri อ่าน | `いち` | `apple` |

> ถ้าไม่ใส่ `speak` ระบบจะประกอบจาก `reading` + `reading2` ให้อัตโนมัติ

### ฟีเจอร์ที่ได้ทันที

- สุ่มคำเป็นรอบตามเวลา (ค่าเริ่มต้น 30 นาที/คำ)
- state ร่วม → ทุกวิดเจ็ตและ lock screen โชว์คำเดียวกัน
- แตะฝั่งซ้าย = ฟังเสียงอ่าน, แตะฝั่งขวา = สุ่มคำใหม่
- พื้นหลังกลางวัน/กลางคืนสลับอัตโนมัติ
- รองรับ Home Screen (medium) และ Lock Screen (`word` / `meaning` ผ่าน widget parameter)

### หมายเหตุเรื่องฟอนต์

`CONFIG.meaningFontBold/Medium` ตั้งค่าเริ่มเป็นฟอนต์ไทย `SukhumvitSet`
ถ้าคำแปลเป็นภาษาอื่น เปลี่ยนเป็น `Font.boldSystemFont` / `Font.mediumSystemFont` ได้
